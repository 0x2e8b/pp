Fonts used by the recorder pages, embedded into their CSS (pages.py), so they look like the Sycope UI.

KumbhSans.woff2   Kumbh Sans (variable, weights 400-600, Latin subset). SIL Open Font License 1.1, OFL-KumbhSans.txt
RobotoMono.woff2  Roboto Mono (weight 400, Latin subset). SIL Open Font License 1.1, OFL-RobotoMono.txt

Both are subsets of the files in github.com/google/fonts (ofl/kumbhsans, ofl/robotomono), made with fontTools
(varLib.instancer, pyftsubset --flavor=woff2).
